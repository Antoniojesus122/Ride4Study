# 🚗 Ride4Study

**Ride4Study** is a web application designed to connect students who travel between different cities or towns for study purposes.  
The platform allows users to **offer** or **request** rides, helping them save money, share daily commutes, and promote sustainable mobility among students.

---

## 🧩 Features

- 👤 **User Management**  
  Register, log in, and manage your profile with secure password encryption.  
  Includes role-based permissions (Admin / User).

- 🚘 **Ride Posts**  
  Users can publish posts offering or requesting transportation.  
  Each post includes origin, destination, departure/return times, and optional pricing.

- 💬 **Chat System**  
  Built-in messaging system that allows users to communicate directly (AJAX-based).

- 🔔 **Email Notifications**  
  Automatic emails for registration, new messages, and key user actions.

- 🔍 **Advanced Search**  
  Filter rides by origin, destination, type, and date with AJAX pagination.

- ⭐ **User Ratings**  
  Evaluate and comment on other users after sharing rides.

- 📱 **Responsive Design**  
  Fully responsive interface made with **Bootstrap/TailwindCSS**.

- 🔒 **Security & Privacy**  
  Input validation, encrypted passwords, and full **GDPR compliance**.
